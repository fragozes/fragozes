## 📁 Projects

### 🔒 [Juice Shop Security Audit](https://github.com/fragozes/juice-shop)
> Security research project on OWASP Juice Shop — a deliberately vulnerable web application.
- Identified and solved real vulnerabilities including SQL Injection, XSS, IDOR, and authentication bypass
- Used manual pentesting techniques alongside OWASP methodologies
- **Stack:** Manual testing, OWASP Top 10, browser DevTools, SQL

---

### 🏥 [Operação HOSP — Reliability & Security Infrastructure](https://github.com/sgsmi/07-reliability)
> 2-week team project: built production-grade reliability and security infrastructure around a legacy veterinary hospital system.
- Implemented NGINX reverse proxy with retry logic, caching, and rate limiting
- Configured AWS WAF, HTTPS/TLS, and audit logging with NGINX njs
- Provisioned all infrastructure with Terraform and automated deployments with GitHub Actions
- **Stack:** AWS (ALB, WAF, EC2), NGINX, Terraform, GitHub Actions, TLS

---

### 🐾 [Poochie Pals — Security Audit](https://github.com/Kart3y/makers_project_team_2)
> Full security audit of a live web application combining SAST, DAST, and AWS infrastructure review.
- Identified 20+ vulnerabilities including SQL Injection PoC, XSS, IDOR, CSRF, hardcoded secrets, and IAM over-permissions
- Applied STRIDE threat modelling to map attack surfaces
- **Stack:** Bearer (SAST), OWASP ZAP (DAST), AWS IAM, Security Groups
